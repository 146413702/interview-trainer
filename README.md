# 运维面试题库 · 语音模拟面试工具（Interview Trainer）

> 基于个人简历定制的运维 / DevOps 面试刷题工具：题库学习、随机小测、错题集、回合制聊天面试、**语音通话式模拟面试**。

## 📌 在线体验

**https://146413702.github.io/interview-trainer/**

（手机 Safari / 电脑 Chrome 打开即可，首次使用需授权麦克风）

## ✨ 功能特性

- **218 道面试题**：按 Linux/Shell、Git/GitLab、CI/CD、Docker、MySQL、Redis、项目实践、故障排查、软技能等 12 个分类组织，答案可直接背诵
- **随机小测**：从未掌握题库中随机抽 5 题作答，自动打分，得分不合格自动进入错题集
- **错题集**：集中沉淀薄弱点，针对性复习
- **回合制聊天面试**：AI 模拟面试官逐题追问，模拟真实面试节奏
- **语音通话式模拟面试**：AI 语音念题 → 你开口回答（讯飞流式实时转写，边说边出字）→ 手动点击"说完了"确认 → AI 才接话。**AI 绝不打断你的表述**，可手动打断，模拟真实通话式面试
- **学习进度本地持久化**：刷题打卡、掌握状态、小测记录全部保存在本地，下次打开继续

## 🛠 技术栈

| 模块 | 技术 |
|---|---|
| 前端 | 纯 HTML / JavaScript 单文件应用（零依赖、零构建） |
| 语音识别 | 讯飞开放平台 WebSocket 流式听写 API（实时转写） |
| 语音合成 | Web Speech API（TTS 朗读题目） |
| 数据存储 | localStorage（本地持久化） |

## 🚀 快速开始

1. **部署**：将 `index.html` 部署到任意静态托管即可（GitHub Pages / Netlify / Nginx）
2. **配置语音 Key**：进入"语音设置"，填入讯飞开放平台的 APPID / APIKey / APISecret；或直接使用带 `#qb_voice=<base64>` 参数的一键导入链接自动写入
3. **手机使用**：Safari / Chrome 打开后授权麦克风 → "语音通话面试" → 开测
